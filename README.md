**Search Query Optimization & Analysis System | DAA Mini Project**

An interactive web-based application developed as a Design and Analysis of Algorithms (DAA) mini project. It demonstrates and compares different searching algorithms, including Linear Search, Binary Search, Hash Lookup, and Optimized Search.

The application allows users to perform searches on datasets, analyze algorithm performance, compare execution time and number of comparisons, generate datasets of different sizes (up to 10,000 records), and run benchmarks to evaluate searching efficiency.

**Key Features:**
- Implementation of Linear Search, Binary Search, Hash Lookup, and Optimized Search.
- Interactive search workspace with multiple search filters.
- Real-time performance analysis and comparison counts.
- Dataset generation with up to 10,000 records.
- Benchmarking of all four algorithms.
- Search history tracking.
- Big-O time complexity analysis.
- Responsive and modern user interface.

**Technologies Used:** HTML, CSS, JavaScript.

**Project Type:** Design and Analysis of Algorithms (DAA) – Mini Project.
