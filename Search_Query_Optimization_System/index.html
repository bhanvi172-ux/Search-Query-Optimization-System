07 / Complexity cheat sheet

Big-O describes how work grows as dataset size increases.

Linear SearchO(n)

Checks records one by one. Works on unsorted data.

Binary SearchO(log n)

Repeatedly halves a sorted index. Best for exact lookup.

Hash LookupO(1) avg.

Uses a hash map for exact keys; collisions can add work.
